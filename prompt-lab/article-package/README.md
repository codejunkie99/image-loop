# start here

Open **index.html** for the finished article. Open **visual-guide.pdf** for the 50-page visual guide. Keep this folder together when moving or sharing it.

- **article.md**: the article in editable Markdown. 3,000 words, counting visible text, headings, captions, prompts, and list markers after removing Markdown syntax, image alternative text, and link destinations.
- **visual-guide.pdf**: six method pages, all 24 official-guide adaptations, and all 20 premium applications. Each study has its actual result, observed limitations, and a prompt or explicitly labeled excerpt. The companion contains every full prompt.
- **prompt-library.html**: full submitted prompts, reference roles, outputs, repairs, and source credits. The JSON and Markdown editions contain the same catalog and experiment ledger.
- **prompts/**: exact saved prompts as plain text. The initial and repair prompts are separate files.
- **evidence/visual-map.html**: the interactive 50-element Rain Engine map. It prepares prompts and JSON; it does not generate images or automatically segment objects.
- **evidence/image-reconstruction-skill/SKILL.md**: the portable agent skill, with schema, validator/compiler, and real examples.
- **evidence/master-image-prompt.md** and **master-image-prompt-v2.md**: full and compact reusable agent instructions.
- **evidence/research-notes.md** and **research-notes-v2.md**: the primary-source research and limits on transferring those findings to these experiments.
- **evidence/experiment-log.md**, **experiment-records.json**, and **expanded-experiments/records/**: original experiment records, including failures.
- **evidence/premium-examples/index.html**: the existing Keep / Refine / Skip review gallery.
- **evidence/image-prompting-guide-v2.html**: the previous comprehensive guide, retained in full.

## evidence limits

The generated studies are exploratory workflow tests. Their tool did not expose the executing model, variant, seed, or quality. They do not establish a GPT Image 2.5 version comparison, a general success rate, or universal prompt superiority. Published OpenAI examples are separately credited. Native Sketch and image comments are documented features; the recorded sketch experiments used uploaded drawings.

The PDF reproduces images for reading; original supplied and generated image files are retained unchanged in evidence/. Personal workspace paths have been removed or replaced with portable references in this public copy. Historical verification files describe the original edition; the parent collection contains the current publication report. A source image does not reveal its original prompt, hidden geometry, exact font, or layers.

P10 (packaging) and P14 (icons) preserve an input-record discrepancy: their original prompts mention an attached design reference, while the saved initial-input lists are empty. The library flags this; reference conditioning for those initial calls is not verified. When reusing either prompt, attach your intended reference or remove the unsupported instruction. The later packaging-to-ad, merch and logo inputs are recorded separately.

# Premium image studies 01

Twenty original AI-generated commercial image concepts, prepared for visual direction review. Open `index.html` in a browser. Images and prompts work offline. Keep/Refine/Skip choices stay in the browser; export them to share the next direction.

The finished images were generated in chat with the built-in image tool. Research and briefs included delegated work. Designer, brand and museum pages informed visual decisions; their pixels were not attached to these new-image generations. Reference transformations use our own earlier generated images.

The tool did not expose a model identifier, seed or quality setting. Do not describe this collection as a verified GPT-2.5 benchmark or a controlled proof that one prompt method outperforms another. There are 20 selected examples and 22 generated candidates, including the fashion-state correction and icon cleanup. Original candidates are retained.

Linked sequences: UGC → headshot; interior → sketch and section; packaging → ad, merch and logo. The sketch example is image-to-sketch restyling, not a test of the manual sketch-input UI. The section invents hidden construction.

Notable limitations: the icons retain faint texture; the infographic values are correct but bar lengths are approximate; interface examples are raster concepts. Each card records additional observations and deviations. `collection.json` contains the same prompts, source links and review notes for agents. `graphics/bar-measurements.json` records the chart check. The source links are included; third-party reference images are excluded from this package.

Pinterest was attempted through Computer Use but remained login-gated. Inspected references came from the linked designer, brand and museum pages. Await the user's choices before expanding these directions or rewriting the article.

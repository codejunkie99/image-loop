# Digital mockups — pixel review

Two original images were generated using the built-in image tool. Both first passes were selected; zero repair calls were used. Prompts were written before generation, and both concepts were reviewed as actual generated pixels at 1536 × 1024. No source photograph was attached to the generator. The reference screenshots were captured with Computer Use by the parent agent and inspected before generation.

## offday — boutique travel booking

The discovery, property and review screens form a coherent visual flow. The courtyard, pool, olive tree and suite doorway plausibly belong to the same fictional property. Main text and controls are readable; no clipped labels or nonsense words were visible. The property name, date span and guest count agree. The cost calculation is correct: €285 × 3 = €855, plus €45 = €900. Explore is selected on the discovery screen, while the detail and review screens use focused back navigation.

The largest limitation is that a raster image cannot demonstrate a working booking flow. These are selected screens, so the room-selection transition is not shown, and the dates lack a year. The imagery is fictional and has not been verified against a real hotel. There was no visual defect significant enough to justify a repair call.

## FORMAE — architecture studio website

The dominant image has a clear architectural subject: a stone hillside property, pool, pergola and distant coast. The smaller timber dining-room and plaster courtyard images are visibly distinct projects. Navigation, wordmark, headline and captions are readable. One dark Start a project button provides a clear primary action. Hairline rules, aligned edges and consistent margins keep the page organized without extra badges or cards.

The lower teasers became almost equal in width rather than the slightly unequal split requested. The result still has a clear hierarchy, so no repair was justified. Architectural plausibility is a visual assessment, not engineering validation. No interaction, responsive layout or accessibility behavior exists in the raster image.

## Reference use

Norm Architects’ [262 Fifth Avenue project](https://normcph.com/project/262-fifth-avenue-2/) demonstrated how dominant photography and restrained navigation can carry the experience. The mockup uses original imagery and keeps its key text on solid backgrounds.

[Welcome Beyond](https://www.welcomebeyond.com/) demonstrated a useful property-card hierarchy: photograph, name, location, capacity and price. The app carries that information hierarchy into a smaller, calmer booking flow. Exact observations and learned decisions are recorded in sources.json.

## Evidence boundary

This is a curated commercial example set, not a controlled experiment. There is no paired baseline, repeated sampling, blinded preference study or measured usability result. The exact prompts, raw-file provenance, checksums and pixel dimensions are retained. Model identifier and seed were not exposed by the built-in tool.

catalog.json paths are relative to this directory. Generation records retain the original output paths; the PNG files here are byte-identical copies.
